# Geu Fee Display

## Overview
It basically reads the fee excel file named as `university`-`fee`.xlsx and displays the fee for the Geu Fee.
there are 4 universities in the excel file:
- Deemed
- Hill-DDN
- Hill-HWD
- Hill-BTL

and each university has one excel file named as `university`-`fee`.xlsx

and each excel file has multiple sheets, each sheet is a different course.


## What it does

It reads the excel file and displays the fee for the Geu Fee with a nice UI in the same table format as the given excel.
